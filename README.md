# IA-aplicada-a-Analise-de-Dados

Objetivo: Este projeto foi desenvolvido com o objetivo de explorar como a Inteligência Artificial pode ser usada como uma ferramenta de aprendizagem ativa e, ao mesmo tempo, como uma aliada prática na análise de dados dentro das empresas. O tema escolhido para o Caderno Temático no NotebookLM foi IA aplicada à Análise de Dados, com foco em três frentes principais: identificação de padrões, automação de processos analíticos e geração de insights estratégicos para apoio à tomada de decisão.
